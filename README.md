# ✦ Academia de Inglês 

Welcome to the official repository for The English Circle (Academia de Inglês) landing page. This project is a modern, responsive landing page designed to present the methodology, community values, weekly study plans, and instructor background for prospective students.

## ★ Project Overview

The English Circle is built around consistency, practical habits, and guided learning — moving away from traditional, rigid textbook study methods. This single-page web application provides a comprehensive showcase of:

- ✦ **Identity & Philosophy:** Language learning through daily integration and active community support.
- ✦ **Your English Week:** A structured weekly roadmap covering Listening, Speaking, Vocabulary, Reading, Writing, and Weekend Final Challenges.
- ✦ **Community Pillars:** Clear differentiation covering guidance, creative practice, personal feedback, and progress tracking.
- ✦ **Instructor Spotlight:** Professional background and vision from Vera (B.A. in European Languages, M.A. in Spanish as a Foreign Language).
- ✦ **Membership Section:** Interactive enrollment section detailing benefits, introductory pricing, and community access.

## ★ Visual Identity & Design System

The landing page features a premium design inspired by the Union Jack color palette:

- **Primary Background (`--uk-blue`):** `#012169` (Deep Royal Navy Blue)
- **Accent Color (`--uk-red`):** `#C8102E` (Vivid Crimson Red)
- **Card Background (`--bg-card`):** `#051636` (Dark Navy Shade)
- **Typography:** `'Outfit'` (Headings & Accents) & `'Plus Jakarta Sans'` (Body Text)

## ★ Features & Highlights
